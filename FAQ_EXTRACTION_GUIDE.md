# 11ty Migration - Complete Setup ✅

## Overview
This branch (`feature/11ty-migration`) contains a complete 11ty static site generator setup for your SLP CONNECT™ Content Hub. It will automatically inject the FAQ enhancement across all 87 FAQ pages without requiring manual edits.

---

## What's Been Created

### Configuration Files
- **`.eleventy.js`** — 11ty configuration with pass-through copy for assets
- **`package.json`** — NPM dependencies and build scripts
- **`netlify.toml`** — Netlify build configuration (publishes `_site` directory)

### 11ty Structure
- **`src/_data/faqs.json`** — FAQ data file (5 samples included, will be populated with 87 FAQs)
- **`src/_layouts/faq-single.html`** — Individual FAQ page template
- **`src/faqs/faq.html`** — Pagination template (generates pages from JSON)
- **`src/faqs/index.html`** — FAQ index page with dynamic category listing

### Extraction Tools
- **`utilities/faq-extractor.js`** — Script to extract all FAQ HTML files into JSON data

### Documentation
- **`MIGRATION_SETUP.md`** — Setup instructions
- **`FAQ_EXTRACTION_GUIDE.md`** — This file

## Step-by-Step Setup

### 1. **Checkout the Migration Branch**
```bash
git checkout feature/11ty-migration
```

### 2. **Install Dependencies**
```bash
npm install
npm install jsdom
```

### 3. **Extract All 87 FAQs**
```bash
node utilities/faq-extractor.js
```

**Output:**
- ✓ Extracts all FAQ HTML files from `static/faqs/`
- ✓ Generates `src/_data/faqs.json` with 87 entries
- ✓ Assigns categories automatically
- ✓ Preserves original HTML formatting

### 4. **Test Locally**
```bash
npm run serve
```

Visit: `http://localhost:8080/faqs/`

You should see:
- FAQ index page with dynamic category listings
- All 87 FAQ pages auto-generated and accessible
- Enhancement injected at the bottom of every FAQ
- All CSS and styling preserved from original

### 5. **Deploy to Netlify**
Push to GitHub:
```bash
git add .
git commit -m "Complete 11ty migration with all 87 FAQs extracted"
git push origin feature/11ty-migration
```

Then create a Pull Request and merge to `main` when ready.

## Troubleshooting

**Q: Script fails with "jsdom not found"**  
A: Run `npm install jsdom` and try again

**Q: `_site` folder not created**  
A: Run `npm run build` to manually build, or `npm run serve` for dev mode

**Q: Enhancement not appearing**  
A: Verify `src/_layouts/faq-single.html` contains the enhancement block

**Q: FAQ content missing**  
A: Check that `src/_data/faqs.json` was populated by running the extractor
